# AGENTS.md

## Setup / runtime
- Node `>=22.23.4` (`.nvmrc`).
- Astro 7, TypeScript (strict, `verbatimModuleSyntax`, `noUncheckedIndexedAccess`), Tailwind CSS v4 via `@tailwindcss/vite`, Cloudflare adapter `@astrojs/cloudflare` 14. Static-first output (`output: 'static'`), sessions disabled. Deploy uses the adapter-generated config: `npm run deploy` runs `astro build && wrangler deploy --config dist/server/wrangler.json`. Root `wrangler.jsonc` intentionally omits `main`/`assets` (filled at build). Secrets via `wrangler secret put <NAME>`.
- Path alias `~/*` → `src/*` (tsconfig + Vite). Imports that use TS extensions must be explicit due to `verbatimModuleSyntax`/`allowImportingTsExtensions` (follow existing style).

## Commands (use these)
- Dev/build/check: `npm run dev`, `npm run build`, `npm run preview`, `npm run check` (Astro), `npm run typecheck` (`tsc --noEmit`).
- Lint/format: `npm run lint`, `npm run lint:fix`, `npm run format`, `npm run format:check`.
- Tests: `npm run test` (vitest run, `tests/**/*.test.ts`, node env). Single test: `npx vitest run tests/tokens.test.ts` or `npx vitest run -t "..."`. Watch: `npm run test:watch`. E2E: `npm run test:e2e` (Playwright, `playwright.config.ts`, specs in `tests/e2e/`; the config boots `npm run dev` on port 4321 — set `PLAYWRIGHT_EXECUTABLE_PATH` to reuse an installed browser).
- Content/translations/migrations: `npm run translate` (needs `OPENAI_API_KEY`; see `scripts/translate.mts` for flags/env), `npm run migrate:extract`, `npm run migrate:media`, `npm run migrate:redirects`.
- Publishing one post: `npm run media:add -- --post <slug> --file <path...>` encodes and uploads the photos, then prints the frontmatter key and the body URLs; `npm run post:ready -- --slug <slug>` translates that post only and runs `check`/`typecheck`/`lint`/`test`/`build`. Neither command commits or deploys.

## Architecture (high-signal)
- **Routing**: custom i18n via single dispatcher `src/pages/[...path].astro` (see `src/lib/locales.ts`). Spanish (`es`) is default at root; others prefixed `/en/`, `/fr/`, `/ja/`, `/zh-TW/`. Do **not** assume Astro built-in i18n layout.
- **Content**: Content Collections in `src/content.config.ts`. Source content lives in `src/content/es/` (`pages/`, `posts/`, `programs/`, `team/`, `categories/`, `tags/`). Other locales generated by `npm run translate` at build time; `src/content/` is ignored by Prettier. Slugs/IDs follow custom rules (see `generateId` in config). Some pages marked `noAutoTranslate`.
- **Media**: Images live in the R2 bucket `frg-media`, served from `https://media.fundacionrosariogaton.org`. Keys are content-shaped, not WordPress paths: `photos/<YYYY-MM-DD>-<evento>/<nn>-<detalle>.webp`, `pages/<pagina>/<nn>-<detalle>.webp`, `programs/<slug>/cover.webp`, `team/<persona>.webp`, `brand/logo.webp`. Frontmatter keeps the relative key and resolves through `mediaUrl()`; **Markdown and block bodies need absolute media URLs**, because Astro's content pipeline resolves bare relative paths as local assets and fails the build with `ImageNotFound`. One WebP object per image at 1600px max width — no originals, no `-WxH` derivatives in the bucket. New photos are published with `npm run media:add`, which owns the naming, the encoding and the upload.
- **Blocks**: Page composition uses typed blocks (`src/lib/blocks.ts`) rendered by `src/components/blocks/*` and orchestrated in `src/components/views/PageView.astro`. The block TypeScript types and Zod schema must stay in sync (`tests/blocks.test.ts`). Adding/changing block shapes requires updating both.
- **Design tokens**: Canonical tokens in `design/tokens.ts` must mirror CSS custom properties in `src/styles/global.css` `@theme` block. Enforced by `tests/tokens.test.ts` — any token change must update both files.
- **Forms/API**: Endpoints in `src/pages/api/*.ts` (contact/donar/voluntariado/newsletter) are the only non-prerendered routes. They use Zod, Turnstile, rate limiting, Resend. Public Turnstile key is client-safe; secrets are server/secret env vars.
- **i18n UI**: Strings in `src/i18n/*.json`, merged via `src/lib/ui.ts` with ES fallback.

## Documentation language
- Human-facing docs (`README.md`, `COMMANDS.md`, `SITE_ADMIN_GUIDE.md`, `POST_AUTHORING_PROMPT.md` and any new guide, manual or prompt for editors) are written in **Spanish**. They are read by the owner and authorised staff, so new human-facing docs follow the same rule.
- Agent-facing files stay in English: `AGENTS.md`, code comments, commit messages and PR descriptions.

## Gotchas
- **Token sync**: If you change colors/fonts/spacing tokens, update `design/tokens.ts` and `src/styles/global.css` together or tests will fail.
- **Content contracts**: `tests/blocks.test.ts` and `tests/content.test.ts` enforce schema/order/slug/locale rules. Don’t guess frontmatter shape — check them.
- **Deploy config**: Never add `main`/`assets` to root `wrangler.jsonc`; deploy from `dist/server/wrangler.json` after `astro build`.
- **Media pipeline**: The order is `npm run migrate:media` (WordPress → legacy `YYYY/MM` keys) → `node scripts/plan-media-keys.mts` (writes `scripts/media-migration.json`) → `node scripts/apply-media-keys.mts --upload --rewrite --verify`. Re-running `migrate:media` after the key migration re-creates the legacy layout, so treat it as the one-time import it was. `--prune` is deliberately not part of the default flow: it deletes the keys the live deployment may still be serving. Photos of **new** posts never touch this pipeline: they go through `npm run media:add`, which uploads and prints the references but leaves the manifest alone.
- **Env**: `TURNSTILE_*`, `RESEND_API_KEY`, `FORM_NOTIFICATION_EMAIL`, `MEDIA_BASE_URL` are defined in `astro.config.ts` env schema. `MEDIA_BASE_URL` defaults to the public R2 media host (`R2_MEDIA_BASE_URL` in `src/lib/media-url.ts`, `https://media.fundacionrosariogaton.org`) — WordPress is no longer a fallback for anything.
- **Translations**: Without `OPENAI_API_KEY`, `translate` won’t translate; missing locales may fall back to ES with “translation pending” behavior noted in project context. Posts older than `POSTS_SINCE` (`2025-01-01` in `scripts/lib/translate.ts`) are skipped by rule — they stay Spanish-only on purpose, and `--force` does not override it.
- **Prettier ignores**: `src/content/`, `dist/`, `.astro/`, `.wrangler/` — don’t reformat generated/imported content.
- **Trailing slashes**: `trailingSlash: 'always'` is set; respect when adding routes/links.
