# AGENTS.md

## Setup / runtime
- Node `>=22.23.4` (`.nvmrc`).
- Astro 7, TypeScript (strict, `verbatimModuleSyntax`, `noUncheckedIndexedAccess`), Tailwind CSS v4 via `@tailwindcss/vite`, Cloudflare adapter `@astrojs/cloudflare` 14. Static-first output (`output: 'static'`), sessions disabled. Deploy uses the adapter-generated config: `npm run deploy` runs `astro build && wrangler deploy --config dist/server/wrangler.json`. Root `wrangler.jsonc` intentionally omits `main`/`assets` (filled at build). Secrets via `wrangler secret put <NAME>`.
- Path alias `~/*` → `src/*` (tsconfig + Vite). Imports that use TS extensions must be explicit due to `verbatimModuleSyntax`/`allowImportingTsExtensions` (follow existing style).

## Commands (use these)
- Dev/build/check: `npm run dev`, `npm run build`, `npm run preview`, `npm run check` (Astro), `npm run typecheck` (`tsc --noEmit`).
- Lint/format: `npm run lint`, `npm run lint:fix`, `npm run format`, `npm run format:check`.
- Tests: `npm run test` (vitest run, `tests/**/*.test.ts`, node env). Single test: `npx vitest run tests/tokens.test.ts` or `npx vitest run -t "..."`. Watch: `npm run test:watch`. E2E exists as `npm run test:e2e` (Playwright) but no config checked in.
- Content/translations/migrations: `npm run translate` (needs `OPENAI_API_KEY`; see `scripts/translate.mts` for flags/env), `npm run migrate:extract`, `npm run migrate:media`, `npm run migrate:redirects`.

## Architecture (high-signal)
- **Routing**: custom i18n via single dispatcher `src/pages/[...path].astro` (see `src/lib/locales.ts`). Spanish (`es`) is default at root; others prefixed `/en/`, `/fr/`, `/ja/`, `/zh-TW/`. Do **not** assume Astro built-in i18n layout.
- **Content**: Content Collections in `src/content.config.ts`. Source content lives in `src/content/es/` (`pages/`, `posts/`, `programs/`, `team/`, `categories/`, `tags/`). Other locales generated by `npm run translate` at build time; `src/content/` is ignored by Prettier. Slugs/IDs follow custom rules (see `generateId` in config). Some pages marked `noAutoTranslate`.
- **Blocks**: Page composition uses typed blocks (`src/lib/blocks.ts`) rendered by `src/components/blocks/*` and orchestrated in `src/components/views/PageView.astro`. The block TypeScript types and Zod schema must stay in sync (`tests/blocks.test.ts`). Adding/changing block shapes requires updating both.
- **Design tokens**: Canonical tokens in `design/tokens.ts` must mirror CSS custom properties in `src/styles/global.css` `@theme` block. Enforced by `tests/tokens.test.ts` — any token change must update both files.
- **Forms/API**: Endpoints in `src/pages/api/*.ts` (contact/donar/voluntariado/newsletter) are the only non-prerendered routes. They use Zod, Turnstile, rate limiting, Resend. Public Turnstile key is client-safe; secrets are server/secret env vars.
- **i18n UI**: Strings in `src/i18n/*.json`, merged via `src/lib/ui.ts` with ES fallback.

## Gotchas
- **Token sync**: If you change colors/fonts/spacing tokens, update `design/tokens.ts` and `src/styles/global.css` together or tests will fail.
- **Content contracts**: `tests/blocks.test.ts` and `tests/content.test.ts` enforce schema/order/slug/locale rules. Don’t guess frontmatter shape — check them.
- **Deploy config**: Never add `main`/`assets` to root `wrangler.jsonc`; deploy from `dist/server/wrangler.json` after `astro build`.
- **Env**: `TURNSTILE_*`, `RESEND_API_KEY`, `FORM_NOTIFICATION_EMAIL`, `MEDIA_BASE_URL` are defined in `astro.config.ts` env schema. `MEDIA_BASE_URL` defaults to the WP uploads host in `src/lib/site.ts` if unset.
- **Translations**: Without `OPENAI_API_KEY`, `translate` won’t translate; missing locales may fall back to ES with “translation pending” behavior noted in project context.
- **Prettier ignores**: `src/content/`, `dist/`, `.astro/`, `.wrangler/` — don’t reformat generated/imported content.
- **Trailing slashes**: `trailingSlash: 'always'` is set; respect when adding routes/links.
