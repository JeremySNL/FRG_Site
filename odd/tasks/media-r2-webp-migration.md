# FRG_Site WordPress media migration to R2 and WebP

Objective: Migrate all first-party media referenced by the site to bucket `frg-media`, publish eligible raster images as WebP, and point the site at the temporary R2 `.dev` host.
Branch: `feat/media-r2-webp-migration`; delivery: `ask-on-risk` (forecast ~500 authored changed lines); chain strategy: `stacked-to-main`; test runner: `npx vitest run --test-timeout=30000`, `npm run lint`, `npm run typecheck`, `npm run check`.

Deduplicate upload keys, report missing local files and external hosts, and do not transfer third-party assets. Check: migration dry-run and focused tests prove all known reference forms are counted without network access.
2. **S2 — R2/WebP migration.** The user authorized: “Si, vamos a migrar todo. Despues de la migracion, cambia todos las URLs para que apunten a las imagenes del bucket ya convertidas en webP.” Upload the site-referenced assets to `frg-media`; generate WebP variants for eligible raster formats and preserve original/unsupported formats without deleting source files. Do not rewrite site URLs until every required upload succeeds. Check: dry-run, upload summary, and URL/object manifest match.
3. **S3 — Temporary endpoint and future domain cutover.** The user specified: “Bueno, como todavia no tengo el dominio en Cloudflare, dejemos eso para despues supongo.” Use the already configured temporary R2 public `.dev` endpoint for this migration; keep the host replaceable for a later custom-domain change. Check: all generated site image URLs resolve from the configured public base; no DNS/domain transfer or deployment is included without separate authorization.
4. **S4 — Destination and credentials.** The user specified: “se llama frg-media es .dev, los secretos estan ahi, hazlo” and “La URL publica ESTA en el .env”. Use bucket name `frg-media` and the existing local R2 credentials/public URL from ignored `.env`; never print or commit secret values. Check: credentials are loaded through an env-file-aware local invocation; bucket and URL are validated before any write.
5. **S5 — URL cutover.** Update every first-party site media reference, including frontmatter, Markdown/HTML body images, site logo, and social/SEO images, to the uploaded WebP variant when eligible, otherwise the uploaded original. Keep third-party external references unchanged. Check: no owned WordPress upload URL or relative image key remains in a rendered site media reference; `MEDIA_BASE_URL`/SEO values resolve to R2.
